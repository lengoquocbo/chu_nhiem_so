# Đa ngôn ngữ

Chuỗi chung nằm trong `messages/vi.json` và `messages/en.json`; helper fallback về tiếng Việt ở `src/lib/i18n.ts`. Locale mặc định `vi`, lưu trong hồ sơ User và cookie. Enum được ánh xạ thành nhãn thân thiện. Muốn thêm ngôn ngữ: tạo tệp messages mới cùng cấu trúc, thêm mã Locale/dictionary và lựa chọn trong bộ chuyển ngôn ngữ.
