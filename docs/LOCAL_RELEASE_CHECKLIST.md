# Checklist phát hành cục bộ

- [ ] Public key đúng fingerprint.
- [ ] Không có private key/dữ liệu issuer trong build khách.
- [ ] License tamper test đạt.
- [ ] Trang nhập/gia hạn license và atomic storage đạt.
- [ ] Mọi mutation được chặn khi hết hạn.
- [ ] Backup/restore drill đạt.
- [ ] Dữ liệu cũ còn nguyên sau gia hạn.
- [ ] Encoding, lint, typecheck, test, E2E, build và audit đạt.
