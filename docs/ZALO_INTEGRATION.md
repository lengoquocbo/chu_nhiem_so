# Tích hợp Zalo OA

Hiện hệ thống dùng IN_APP/MOCK và không tuyên bố gửi Zalo thật. Khi tích hợp cần Zalo OA hợp lệ, API chính thức, secret trong biến môi trường, webhook xác minh chữ ký, hàng đợi retry, trạng thái gửi và sự đồng ý của giáo viên sau bước xem trước. Không dùng tài khoản Zalo cá nhân để tự động hóa.
