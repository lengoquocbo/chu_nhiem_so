# Hướng dẫn license dành cho khách hàng

Ứng dụng sẽ chỉ nhận public key và file license. Không gửi private key cho khách hàng. Trang nhập license chưa hoàn thiện trong lát cắt hiện tại. Khi hết hạn, dữ liệu phải được giữ nguyên và ứng dụng chuyển sang chỉ đọc; khách vẫn được sao lưu và xuất dữ liệu.
